# Blog posts

Create one Markdown file per post in this folder. Name it `YYYY-MM-DD-short-title.md` using the publication date and a lowercase title with hyphens. Start the file with a single `#` heading, add a blank line, then write the article.

```markdown
# How I tested a data pipeline

Start the article here.
```

Run `npm start` and open the Blog to preview it. Commit the new `.md` file and push to `main` to publish with the next Vercel deployment. Any article in this folder is public once pushed, so keep drafts elsewhere.
