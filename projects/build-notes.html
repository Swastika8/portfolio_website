Build notes

Projects I’m building, each with a different take on a hackathon-winning idea. The source repositories are private.

API Regression Gate

I’m building a CI check that runs the same k6 workload against baseline and candidate builds of a sample API. The check is designed to flag changes in p95 latency or error rates that cross a defined threshold.

The verification case adds a controlled delay to one route and checks whether the report isolates it.

Inspired by kassi, Grand Prize winner at the Splunk Agentic Ops Hackathon.

PostgreSQL Migration Review

I’m building a CLI to rehearse migrations in a disposable PostgreSQL instance. It compares the before-and-after schemas and reports risky changes such as dropped columns or tightened constraints.

The test cases cover a migration that adds a column and one that fails against seeded records.

Inspired by vdbs, Best Overall Project at the Supabase Open Source Hackathon 2024.

Rules Compiler

I’m building a C++ compiler for a small language that filters JSON records. The language supports comparisons and Boolean expressions, with bytecode output and line-and-column errors for invalid rules.

The test cases cover operator precedence, missing operands, and invalid fields.

Inspired by goboscript, a prize winner at FOSS Hack 2025.

Keyboard Outline

I’m building a browser extension that creates a keyboard-navigable outline of the active page’s headings and landmarks. The focus behavior is designed to let users jump to a section and return to where they started.

The keyboard and screen-reader checks cover skipped heading levels and repeated landmark names.

Inspired by the Universal Access Browser Extension, winner of the Breaking Barriers Award at CloudFest Hackathon 2026.
