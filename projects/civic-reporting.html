La Trobe Grand Challenge

Smart Public Issue Reporting

A mobile app for reporting civic issues with a location, category, and trackable status.

Sample report

Blocked footpath

Submitted

How a report moves through the app

  1. Describe the issue

    The reporter enters what happened, chooses a category, and attaches a location.

  2. Submit the report

    The Flutter client sends the report to the Flask API, which stores it for later lookup.

  3. Check its status

    The client reads the stored report and displays its current status.

My contribution

I led the student team and designed the Flask REST APIs, relational database schemas, and API contracts. I also coordinated the Flutter-to-backend integration so the mobile client and database agreed on how a report was created and retrieved.
