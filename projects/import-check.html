Import Check

Compare two data contracts before a spreadsheet reaches an ETL pipeline.

Compare contracts

Types include string, integer, number, boolean, date, and datetime.

Why this build

Enola handles messy rows. Import Check catches a different failure before loading starts, a field disappearing or changing type.

The API checks the two declarations and returns missing fields, new fields, and type changes. It uses synthetic sample contracts.

Inspired by Schema-Drift Auto-Repair Agent, a challenge winner at Build with DataHub: The Agent Hackathon.
