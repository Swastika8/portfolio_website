Orbital visualization

ORION

Orbital Risk Intelligence & Observation Network is a project for tracking satellites and investigating close approaches in a 3D view of Earth.

View source on GitHub

From orbit data to a 3D view

I worked across the stack, from FastAPI endpoints and PostgreSQL queries to the Three.js viewer. The project uses SGP4 to estimate where satellites will be at a given time, then displays those positions in the viewer.

Finding nearby objects

Checking every possible pair gets expensive as the object catalog grows. I used a SciPy KDTree to look up nearby objects and narrow the set of pairs the system needs to check.

Rendering a large catalog

For the visualization, I used GPU instancing so many orbital objects could share geometry and render together. This avoids issuing a separate draw call for every object.
